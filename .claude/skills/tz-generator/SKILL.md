# TZ Generator — скилл работы с репозиторием

Веб-сервис на Flask: пользователь отвечает на вопросы формы → получает готовое
техническое задание (облегчённое бесплатно / по ГОСТ за 100 ₽ через ЮMoney),
скачивает в .md или .docx. Текст полируется через YandexGPT (OpenAI-совместимый API).

## Структура репозитория

| Путь | Что это |
|---|---|
| `app.py` | Ядро: маршруты, шаблоны ТЗ (`build_light_tz` / `build_gost_tz`), ИИ-полировка (`ai_polish`), конвертация в .docx, SEO (robots/sitemap) |
| `templates/` | Jinja2-шаблоны: `base.html` (каркас + мета), `index.html` (главная), `form.html` (опросник), `result.html` (результат + скачивание), `example.html`, `gost_pay.html` (оплата) |
| `static/` | `style.css`, скриншоты для README в `screenshots/` |
| `payments.py` | **Приватный модуль** — приём оплаты ЮMoney. Есть только локально и на сервере (`/opt/tz-private/`), в репозиторий и docker-образ НЕ входит |
| `notify.py` | **Приватный модуль** — Telegram-уведомления. Аналогично не публикуется |
| `.env` | Секреты (ключи ЮMoney/Яндекса/ТГ). В git не попадает, есть образец `.env.example` |
| `Dockerfile` | Образ: python:3.11-slim, gunicorn на 0.0.0.0:5001 |
| `CLAUDE.md` | Лог прогресса и правила проекта |

## Запуск локально (Windows PowerShell)

```powershell
cd F:\Portfolio\tz-generator
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py          # http://localhost:5000
```

Без `.env`, `payments.py` и `notify.py` сервис тоже работает: оплата отдаёт
страницу-заглушку, уведомления молча пропускаются (`_SilentNotify`) — это
заложено в app.py через try/except импорты. Секреты берутся только из env,
в код никогда не вписывать.

## Внесение изменений

- Структуру ТЗ менять в `app.py`: `build_light_tz()` (облегчённое) и
  `build_gost_tz()` (ГОСТ). Поля формы — в `templates/form.html` + словарь `a`
  в `generate()`: новое поле добавляется в оба места.
- Промпт ИИ-полировки — константа `POLISH_PROMPT` в `app.py`.
- Тексты страниц/мета-описания — в шаблонах (`base.html` — дефолтное описание,
  `index.html` — своё). Не дублировать тексты герой-блока в SEO-блоке.
- Стили — `static/style.css`; дизайн в духе medvejka.ru (тёмный фон, золото).
- Перед изменением прочитать релевантный кусок файла, менять только необходимое,
  структуру сохранять.

## Проверки перед коммитом

```powershell
python -m py_compile app.py          # синтаксис
# ручной прогон: обе формы (/form/light, /form/gost), генерация, скачивание .md/.docx
```

Платный ГОСТ закрыт сессией (`session["gost_paid"]`): без метки оплаты
`/form/gost` и `/generate` (mode=gost) редиректят на `/gost/pay`. Проверять
test_client: доступ без оплаты → редирект; после мока `gost_paid=True` → форма.

## Публикация и деплой

- `git commit` свободно; `git push` — только по явному «заливай» Медвежки.
- **Никогда не публиковать:** `payments.py`, `notify.py`, `payments.log`,
  `.env`, `*.docx`, QR-коды с реквизитами (см. `.gitignore`).
- Продакшн: Dokploy, контейнер `services-tzgenerator-ofhoco`, домен
  tz.medvejka.ru (порт 5001). Приватные модули монтируются bind-mount из
  `/opt/tz-private/`. Env задаётся в Dokploy UI → Environment — после правки
  проверять, что там нет заглушек вида `<токен бота>`.
- После изменения env/кода: Redeploy в Dokploy, затем живой тест
  (оплата 100 ₽ → форма → генерация → скачивание → уведомления в ТГ).
