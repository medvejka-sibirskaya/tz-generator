# TZ Generator — генератор технических заданий

## Что это

Финальный проект курса «Вайб-кодинг на Claude Code» (ZeroCoder, CLm04) и монетизируемый продукт. Веб-сервис: пользователь отвечает на вопросы → генератор выдаёт готовое ТЗ.

## Описание проекта (структура школы, 7 пунктов)

1. **Название:** Генератор технических заданий (TZ Generator)
2. **Проблема:** фрилансеры и малые команды пишут ТЗ вручную — долго, без структуры, отсюда споры с заказчиком о объёме работ.
3. **Пользователь:** фрилансеры, студии 1–3 человек, заказчики, формулирующие задачу подрядчику.
4. **Основная функция:** веб-страница с формой-опросником → генерация готового ТЗ. Два режима:
   - **Облегчённый** — бесплатно, минимальная структура;
   - **По ГОСТ (19/34)** — 100 ₽, полная структура: стадии, требования, разделы. Ядро — методичка/шаблон по ГОСТ (сопутствующий скилл tz-gost).
5. **Формат результата:** готовое ТЗ на экране + скачивание .md / .docx.
6. **Минимальный функционал (MVP):** форма → облегчённое ТЗ; режим ГОСТ; скачивание файла; живая оплата ЮMoney для ГОСТ-режима.
7. **Технологии:** Python, Flask, HTML/CSS, шаблоны ТЗ, генерация текста через LLM API (ключи — только в env, не в коде).

## Монетизация (правило Медвежки с 21.09)

- Все проекты оцениваются по деньгам/репутации. Схема здесь: облегчённый бесплатно (привлечение) + ГОСТ за 100 ₽ (доход).
- Оплата **живая** через ЮMoney (как в уроке NS06.1 n8n-курса). Секреты платежей — в env, не в репозитории.
