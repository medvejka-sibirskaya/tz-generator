# TZ Generator — план тест-ревью (20.10.2026)

Прод: https://tz.medvejka.ru · Repo: github.com/medvejka-sibirskaya/tz-generator
Стек: Python 3.11 + Flask, gunicorn (1 воркер), Dokploy/Swarm на сервере Медвежки.

## 1. Архитектура (кратко)

- **app.py** — маршруты: `/`, `/form/<mode>` (light/gost), `/generate`, `/result/<id>`,
  `/download/<id>`, `/download_docx/<id>`, `/example`, robots/sitemap.
- **admin.py** — blueprint `/admin`: вход по `ADMIN_TOKEN` (env), журнал платежей,
  ручное открытие доступа `POST /admin/grant`.
- **payments.py** (ПРИВАТ, вне репо, bind-mount из `/opt/tz-private/`) — деньги:
  - `/gost/pay` — метка `tz-gost-XXXX` в сессии → ссылка ЮMoney quickpay;
  - `/gost/notify` — callback ЮMoney: подпись **HMAC-SHA256** (поле `sign`,
    поля кроме sign — по алфавиту, `key=значение`, urlencode RFC3986) →
    сумма ≥ 100 ₽, RUB, метка `tz-gost-`, идемпотентность по журналу;
    подтверждение = запись в журнал `status: confirmed` + токен вечной ссылки;
  - `/gost/paid` — возврат с оплаты: есть подтверждение → страница успеха
    с вечной ссылкой; нет → страница-ожидание (автообновление ~1,5 мин) → fallback;
  - `/gost/access/<token>` — восстановление доступа по вечной ссылке (журнал).
- **notify.py** (ПРИВАТ) — Telegram-уведомления.
- **Журнал `payments.log`** — bind-mount `/opt/tz-private/payments.log`:
  подтверждения, токены доступов, отказы с причинами. Переживает Redeploy.
- **Секреты** — только env Dokploy: `YOOMONEY_RECEIVER`, `YOOMONEY_SECRET`,
  `ADMIN_TOKEN`, `LLM_*` (ЯндексGPT), `TG_*`, `SECRET_KEY`, `APP_URL`.

## 4. Известные хвосты / риски (после сеньор-ревью, 20.10)

Отработано по ревью:
- **Сумма с комиссией:** проверяется `withdraw_amount` (заплатил покупатель),
  а не `amount` (зачисление после комиссии, при 100 ₽ картой приходит 97 ₽).
  Оба поля логируются в отказах. Тест «commission-97» — PASS.
- **Fail-closed:** на проде (`APP_URL` = https) без `YOOMONEY_SECRET` доступ не
  открывается (`/gost/paid` → 503, `/gost/notify` → 500); legacy-режим доверия
  остался только для localhost — тесты `failclosed` PASS.
- **Вечные ссылки:** подтверждённые платежи хранят токен, есть
  `/gost/access/<token>`; ручные гранты получают токен при первом заходе.
- **Telegram не роняет уведомление:** отправка в фоновом потоке с try/except,
  журнал пишется ДО Telegram (проверено в notify.py).
- **codepro=true отвергается** (обязательный codepro=false) — есть тест.
- **Метка в сессии потерялась после таймаута** (контрольный платёж 16:29
  пришёл с пустой меткой): fallback — вечные ссылки и админка; TODO —
  не чистить `gost_label` на таймауте, чтобы позднее уведомление нашло метку.

Осталось (не блокер):
- **docker ps показывает 5 running-контейнеров** при replicas=1 (хвосты tasks
  не убираются) — запросы могут попадать в разные инстансы, `TZ_STORE` в памяти
  даст случайные 404 на `/result/<id>`. Почистить в Dokploy/на хосте.
- gunicorn `--timeout` дефолтный 30 с, полировка Яндекса до 60 с — поднять
  timeout (изменение Dockerfile → Redeploy).
- Повторные сессии с одной метки: идемпотентность по метке, не по operation_id
  (осознанно: метка выдаётся на каждую оплату новая).
- Чеки «Мой налог» — вручную (напоминание уже приходит в ТГ-уведомлении).
- Бэкап `payments.log` вне сервера — сделать сейчас, локальная копия есть.
