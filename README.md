# TZ Generator — генератор технических заданий

Веб-сервис, который превращает ответы на несколько вопросов в готовое техническое задание.

**Без хорошего ТЗ получается ХЗ** — поэтому фрилансеры и малые команды тратят часы на переписку с заказчиком: объём работ размыт, правки бесконечны, спорить не о чем. TZ Generator структурирует задачу за 5 минут и выдаёт документ, который можно приложить к договору.

**Онлайн: [tz.medvejka.ru](https://tz.medvejka.ru)**



## Что умеет

- **Облегчённое ТЗ — бесплатно.** Скелет ТЗ (цель, проблема, ЦА, требования по MoSCoW, сроки, критерии приёмки) + типовые блоки под тип проекта: бот, ИИ-ассистент, автоматизация, скрипт, сайт, дизайн.
- **ТЗ по ГОСТ (19/34) — 100 ₽.** Полная структура: стадии работ, требования к системе, порядок приёмки. Оплата через ЮMoney, подтверждается автоматически (HMAC-подпись уведомления).
- **ИИ-полировка текста.** Черновик вычитывает языковая модель ЯндексGPT: лёгкая модель (yandexgpt-lite) — бесплатно, старшая (yandexgpt-5.1) — в платном ГОСТ-режиме. Если API недоступен — сервис работает без полировки, генерация не ломается.
- **Экспорт** в Markdown и .docx — можно сразу отправить заказчику.
- **Telegram-уведомления** исполнителю: оплата и каждое скачивание ТЗ.
- **Вечная ссылка доступа.** После подтверждения оплаты покупатель получает ссылку, которая восстанавливает доступ в любом браузере; число генераций по ней ограничено.

## Стек

- Python 3.11 + Flask
- SQLite не используется — хранение в памяти процесса (MVP); журнал платежей — файл
- ЯндексGPT (OpenAI-совместимый API): lite — бесплатный режим, yandexgpt-5.1 — ГОСТ
- ЮMoney quickpay для приёма платежей
- python-docx для экспорта

Никаких тяжёлых моделей и эмбеддингов — сервис работает на самом дешёвом VPS.

## Запуск локально

```bash
git clone <repo>
cd tz-generator
python -m venv venv
venv\Scripts\pip install -r requirements.txt   # Windows
copy .env.example .env                          # и заполнить переменные
venv\Scripts\python.exe app.py
```

Открыть http://localhost:5000

## Переменные окружения (.env)

| Переменная | Назначение |
|---|---|
| `YOOMONEY_RECEIVER` | Номер кошелька ЮMoney для приёма оплаты |
| `YOOMONEY_SECRET` | Секретное слово HTTP-уведомлений ЮMoney (обязательно на проде) |
| `SECRET_KEY` | Ключ подписи cookie-сессий (обязателен на проде) |
| `ADMIN_TOKEN` | Ключ входа в админ-панель `/admin` (ручное открытие доступа) |
| `APP_URL` | Публичный адрес (для successURL оплаты, sitemap) |
| `ALLOW_LEGACY_PAYMENTS` | `1` — legacy-режим доверия, только локальная разработка; на проде не ставить |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` / `LLM_MODEL_PRO` / `LLM_FOLDER_ID` | Доступ к LLM-полировке. Пусто = работает без ИИ |
| `TG_BOT_TOKEN` / `TG_ADMIN_CHAT_ID` | Telegram-уведомления. Пусто = без уведомлений |

Секреты только в `.env` — в репозиторий не попадают.

## Монетизация

Облегчённый режим бесплатный (привлечение), ТЗ по ГОСТ — 100 ₽ (доход).
Оплата подтверждается автоматически: сервер проверяет HMAC-подпись уведомления ЮMoney,
комиссию берёт из `withdraw_amount`, после подтверждения выдаётся вечная ссылка доступа.
Без секрета в окружении доступ не открывается (fail-closed).

## Структура

```
tz-generator/
├── app.py            # Flask: генерация, экспорт, SEO, /healthz
├── admin.py          # админ-панель /admin (журнал, ручные гранты)
├── notify.py         # Telegram-уведомления (приватный модуль, не публикуется)
├── payments.py       # приём оплаты ЮMoney (приватный модуль, не публикуется)
├── Dockerfile        # контейнер: не-root user, healthcheck, gunicorn 120 с
├── templates/        # index, form, result, gost_pay, gost_access, admin, ...
├── static/style.css  # стили (тёмная тема, без фреймворков)
└── .env.example      # шаблон переменных окружения
```
Журнал платежей (`payments.log`) создаётся сервисом в рантайме; `notify.py`
и `payments.py` — приватные локальные модули, в репозиторий и образ не входят.
